# Chronos Pomodoro

Timer Pomodoro para estudos e foco, desenvolvido como projeto de estudo de React com TypeScript.

## Tecnologias

- React
- TypeScript
- Vite
- CSS
- ESLint e Prettier

## Estrutura

A interface foi organizada em componentes reutilizáveis: Container, Countdown, DefaultInput, Heading, Logo e Menu.

## Como rodar

```bash
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:5173`.
